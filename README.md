# Public Transport Management

A simple console-based C++ project for managing routes, buses, passengers, and ticket bookings. It tracks bus seat availability and lets you view saved records while the program is running.

## Build and run

```bash
g++ -std=c++11 mai.cpp -o transport_management
./transport_management
```

On Windows, run the compiled program with:

```powershell
.\transport_management.exe
```

Data is kept in memory and is cleared when the program exits.
